# Job Result Cache Directory

This directory holds the final cached JSON outputs generated by the scraping engines after passing through the query and date filter stages.

## Directory Contents & File Mapping

All `.json` files in this folder contain structured, deduplicated job postings updated within a 24-hour window.

* **`AIEngineer.json`**: Stores cached roles for AI Engineers, ML Engineers, Data Engineers, and Python Developers.
* **`Designer.json`**: Stores cached roles for UI/UX Designers, Product Designers, and Graphic Designers.
* **`Fullstack.json`**: Stores cached roles for Frontend, Backend, React, Node, and Full-Stack Developers.
* **`MobileDeveloper.json`**: Stores cached roles for React Native, Flutter, iOS, and Android Developers.
* **`SoftwareEngineer.json`**: Stores cached roles for DevOps, Cloud, AWS, and Systems Software Engineers.

## Git Rules & Cache Privacy

To ensure dynamic scrape data is not tracked in your GitHub history while keeping this directory structure intact:

1. All `.json` results inside this folder are ignored by Git.
2. This `Job-Result-setup.md` file remains tracked to document the folder layout.

### Updated `.gitignore` Setting

Make sure your `.gitignore` ignores only the `.json` cache files rather than the entire directory:

```gitignore
# Ignore JSON result caches inside Data/Job-Result-cache
Data/Job-Result-cache/*.json
!Data/Job-Result-cache/Job-Result-setup.md
